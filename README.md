# Blood-report-Analysis
Blood Work Analyzer is an AI-powered web application that analyzes blood test reports, identifies abnormal values, provides a simple health summary, and recommends a personalized Indian diet plan based on the blood test results.

# Blood Work Analyzer


 ##Features
- Upload or paste blood test report
- Detect abnormal blood parameters
- Generate an easy-to-understand health summary
- Recommend a personalized Indian diet plan
- Built using Streamlit and Google Gemini

## Technologies Used
- Python
- Streamlit
- LangChain
- Google Gemini API
- HTML/CSS
